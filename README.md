# Savory Food Fusions — El Paso, TX

Static website for the Savory Food Fusions food truck. Hosted on GitHub Pages.

## Edit
- `index.html` — all content (menu items, schedule, contact, catering copy)
- `styles.css` — colors, fonts, layout
- `images/` — menu photos (`.jpg`) and logo

## Common updates
- **Prices:** search `$—` in `index.html` and replace.
- **Weekly schedule:** edit the `.schedule__row` lines under `#find`.
- **Phone/email:** edit the `#contact` section (both the `href` and the visible text).
- **Contact form:** create a free form at formspree.io and replace `YOUR_FORM_ID`.
- **Social links:** replace the Instagram/Facebook URLs under `#find`.

## Deploy
Pushes to `main` publish automatically via GitHub Pages (Settings → Pages → Deploy from branch → main / root).
